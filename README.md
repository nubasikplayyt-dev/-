# Lingvo Island 🇪🇸 🇩🇪

Android-приложение для ежедневного изучения испанского и немецкого: два независимых словаря,
интервальное повторение по алгоритму FSRS-5, пополнение словарей через Claude (JSON),
напоминания и компактный прогресс тренировки в стиле Dynamic Island.

Без регистрации, сервера, рекламы и интернета: все данные хранятся на телефоне.

## Возможности

- **Два раздела** — испанский и немецкий: свои словари, очереди, настройки, статистика и история.
- **Новые слова** небольшими порциями (5/10/15/20 в день на язык, по умолчанию 10). Знакомство ≠ «выучено»:
  карточка сразу попадает в повторение.
- **Интервальное повторение FSRS-5**: активное вспоминание, «Показать ответ», оценки
  «Не вспомнил / С трудом / Хорошо / Легко» с подписью следующего интервала. Направления: изучаемый → русский,
  русский → изучаемый или смешанно. Немецкие существительные всегда с артиклем.
- **Прогресс сохраняется после каждого ответа**; прерванную сессию можно продолжить.
- **Статусы**: новое, изучается, на повторении, хорошо запоминается, устойчиво усвоено, приостановлено —
  по состоянию алгоритма и истории ответов, с пояснением.
- **Словарь**: поиск по слову и переводу (без учёта ударений), фильтры по языку, статусу, части речи,
  категории, уровню, дате повторения; добавление по одному и списком; проверка дубликатов.
- **Импорт/экспорт JSON**: файл, Sharesheet, буфер обмена, HTTPS-ссылка (например, raw-файл из GitHub); предварительный отчёт (новые, изменённые,
  без изменений, пропущенные, ошибки, конфликты); транзакционный импорт; повторный импорт без дубликатов;
  ничего не удаляется.
- **Экспорт словами**: текст, Markdown, CSV и документ Word (.docx); отправка отфильтрованного списка из словаря.
- **Резервные копии** со всем прогрессом и настройками + автоматические копии перед импортом.
- **Напоминания** (по умолчанию в 19:00 и только если есть что повторять): время, дни, до 3 раз в день,
  тихие часы, отдельно по языкам, объединение, приватность.
- **Dynamic Island-подобный интерфейс**: одно обновляемое уведомление с прогрессом
  (на Android 16+ — Live Update с чипом в строке состояния), необязательная плавающая капсула,
  «остров» прогресса на экране тренировки.
- **Статистика**: неделя/месяц, календарь активности, серии, доля сложных карточек, история занятий,
  отключаемые достижения.
- Material 3, светлая/тёмная тема, динамические цвета, поддержка крупного шрифта.

## Установка

1. Откройте вкладку **Actions** репозитория → последний успешный запуск **Android build** →
   артефакт **lingvo-island-apk** (zip с APK).
2. На телефоне установите `app-release.apk` (или `app-debug.apk`), разрешив установку из этого источника.
3. При первом запуске загрузите стартовый набор или импортируйте свой словарь.

Сборка вручную (Android Studio Ladybug+ / JDK 17+):

```bash
./gradlew :app:assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

Release подписан debug-ключом — для личной установки. Для публикации замените `signingConfig`.

## Технологии

Kotlin 2.2, Jetpack Compose + Material 3, Navigation Compose, Room 2.7 (KSP), DataStore, Coroutines/Flow,
WorkManager + AlarmManager, Notifications API (ProgressStyle / Live Updates на Android 16),
TextToSpeech, kotlinx.serialization. minSdk 26 (Android 8.0), targetSdk 36 (Android 16).

## Архитектура

```
core/  — чистый Kotlin, тестируется без Android
  Fsrs.kt            FSRS-5: стабильность, сложность, шаги изучения, интервалы
  VocabularyJson.kt  разбор и валидация словарей, сериализация в канонический формат
  ImportPlanner.kt   сопоставление (ID → нормализованное выражение), слияние, конфликты
  ReminderPlanner.kt расписание напоминаний, тихие часы, решение «показывать или нет»
  Learning.kt        статусы, серии, тексты уведомлений; Session.kt — очередь сессии; Backup.kt
app/
  data/    Room (VocabularyEntry, ReviewState, ReviewLog, LearningSession, ImportHistory), DataStore, репозиторий
  notify/  каналы, напоминания, действия уведомлений, восстановление после перезагрузки
  island/  контроллер компактного интерфейса и плавающая капсула
  ui/      экраны Compose
vocabulary/ — канонические словари; tools/vocab_tool.py — их безопасное пополнение
```

Данные карточки и данные повторения хранятся раздельно: правка карточки или импорт не сбрасывают прогресс,
а карточки одного языка не попадают в очередь другого.

## Тесты

```bash
./gradlew :core:test -PcoreOnly=true    # без Android SDK
./gradlew :core:test :app:testDebugUnitTest
python3 tools/vocab_tool.py validate
```

Покрыто: FSRS (интервалы, ошибки, рост интервалов, порядок оценок), разбор JSON (повреждённый/пустой файл,
чужой язык, обязательные поля, артикли, орфография), импорт (повторный импорт, слияние, конфликты, изоляция
языков, отсутствие удаления), сессии (повтор ошибок, возобновление), статусы, серии, напоминания (дни, тихие
часы, смена часового пояса, решение об отправке), резервные копии, фильтры словаря, статистика.
