# Lingvo World 🌍

Android-приложение для ежедневного изучения **любых языков**: языковые курсы с произвольной парой
«изучаемый → перевод», интервальное повторение FSRS-5 с двумя кнопками «Помню»/«Не помню», ежедневные серии,
достижения, карта языкового мира, коллекция существ-полиглотов и альтернативные иконки приложения.

Без регистрации, сервера, рекламы и интернета: все данные хранятся на телефоне.

## Возможности

- **Любые языки и курсы.** При первом запуске вы сами выбираете языки (из 30+ или свой). Можно завести несколько
  курсов, в том числе с одним языком и разным языком перевода. Ничего не создаётся автоматически.
- **Повторение двумя кнопками** — «Помню» и «Не помню» — поверх FSRS-5 (Good/Again). Карточка переворачивается,
  ответ сразу сохраняется, прерванное занятие продолжается. Можно повторить конкретное слово из словаря.
- **Ежедневная цель и серия.** День засчитывается, когда дано N ответов (5–50). «Оживающий глобус» сияет ярче
  с ростом серии, календарь показывает выполненные дни, рекорд сохраняется.
- **Достижения (25)** в пяти категориях с иллюстрациями, прогрессом, датой и анимацией получения. Главная награда —
  **альтернативные иконки приложения (19)**.
- **Карта языкового мира**: 8 областей открываются по порядку за реальный прогресс, в каждой — находка.
- **Существа-полиглоты (9)** четырёх редкостей: появляются за прогресс, растут (3 облика), живут на карте,
  выбранный спутник сопровождает на главном экране и в «острове» занятия.
- **Словарь**: поиск без учёта ударений, фильтры по курсу, статусу, части речи, категории, уровню, дате.
- **Импорт/экспорт**: JSON (файл, Sharesheet, буфер, HTTPS-ссылка), текст, Markdown, CSV, Word (.docx),
  полные резервные копии с прогрессом, сериями и наградами.
- **Напоминания** в выбранное время — только пока цель дня не выполнена; разнообразные дружелюбные тексты.
- **Dynamic Island-подобный интерфейс**: яркий «остров» занятия, уведомление с прогрессом (Live Update на Android 16+),
  необязательная плавающая капсула.
- Светлая тема по умолчанию (тёмная и системная — по выбору), крупные кнопки, анимации можно отключить.

## Установка

1. Вкладка **Actions** → последний успешный запуск **Android build** → артефакт **lingvo-island-apk** → `app-release.apk`.
2. Установите APK на телефон. Обновление поверх старой версии (Lingvo Island) сохраняет все слова и прогресс.

```bash
./gradlew :app:assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

## Технологии

Kotlin 2.2, Jetpack Compose + Material 3, Navigation Compose, Room 2.7 (KSP, миграции), DataStore, Coroutines/Flow,
WorkManager + AlarmManager, Notifications API (ProgressStyle / Live Updates), activity-alias для иконок,
TextToSpeech, kotlinx.serialization. minSdk 26, targetSdk 36. Сторонних библиотек сверх AndroidX/Kotlin нет.

## Архитектура

```
core/  — чистый Kotlin, тестируется без Android
  Language.kt        каталог языков, Course, LanguageSpec (бизнес-логика не знает конкретных языков)
  Fsrs.kt            FSRS-5 + Answer («Помню» → Good, «Не помню» → Again)
  Streak.kt          дневная цель и серии
  Game.kt            метрики, достижения, карта, существа, иконки, GameEngine
  VocabularyJson.kt  словари JSON (совместимы со старыми spanish/german)
  ImportPlanner.kt, ReminderPlanner.kt, Learning.kt, Session.kt, Backup.kt, TextExport.kt
app/
  data/    Room v2 (+ course, unlock, daily_progress), миграция 1→2, репозиторий, ProgressCalculator
  ui/      дизайн-система (Design.kt, Art.kt — векторные существа и глобус), экраны, навигация
  notify/  напоминания и уведомления; island/ — «остров» и капсула; IconSwitcher — смена иконки
```
