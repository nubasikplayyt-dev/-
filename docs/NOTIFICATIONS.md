# Напоминания

**Настройки → Напоминания.**

По умолчанию: одно напоминание в день в 19:00, только если есть карточки к повторению. Пример:
«Время повторить испанский 🇪🇸 — Сегодня тебя ждут 12 слов. Удели им 4 минуты»; для двух языков —
«Время повторить языки — 🇪🇸 8 слов · 🇩🇪 12 слов».

Настраивается: включение, время (до 3 раз в день), дни недели, тихие часы (в том числе через полночь),
напоминания по каждому языку, объединение в одно уведомление, показ на экране блокировки.

Нажатие открывает тренировку нужного языка (если сессия была прервана — продолжает её).
Кнопка «Отложить на час» повторит напоминание через час, если слова ещё не повторены.

## Как это работает

- Планирование — `AlarmManager.setAndAllowWhileIdle` (неточный будильник без особых разрешений).
  Android может сдвинуть срабатывание на несколько минут для экономии батареи — точность до минуты не гарантируется.
- В момент срабатывания `WorkManager` проверяет очередь: если повторять нечего, вы занимались меньше часа назад,
  сейчас тихие часы или день выключен — уведомления не будет.
- После перезагрузки, смены времени, часового пояса или обновления приложения расписание пересчитывается
  (время остаётся «местным», например 19:00 в новом часовом поясе).
- Нет постоянного фонового сервиса, wake lock и опроса базы.

## Если напоминания не приходят

1. Android 13+: разрешите уведомления (Настройки → «Разрешить уведомления»).
2. Проверьте, что канал «Напоминания о повторении» включён в системных настройках уведомлений.
3. На некоторых прошивках (Xiaomi, Huawei, Samsung с агрессивной экономией) включите для приложения
   «Без ограничений» в настройках батареи. Приложение не требует этого по умолчанию.
4. «Проверить напоминание сейчас» в настройках покажет уведомление сразу, если есть карточки к повторению.
