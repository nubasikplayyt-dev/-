# Dynamic Island-подобный интерфейс

«Dynamic Island» — интерфейс Apple. В Android нет единого публичного API для него, поэтому приложение
использует стандартные средства и выбирает лучший вариант, доступный на устройстве.

## Уровень A — уведомление с прогрессом (по умолчанию)

Во время незавершённой тренировки показывается **одно** обновляемое уведомление:
«🇪🇸 Испанский · 7/15», полоса прогресса, «Осталось 8 карточек».

- Android 16+: уведомление оформлено `ProgressStyle` и запрашивает статус **Live Update**. Если система
  разрешает, прогресс показывается чипом в строке состояния и на экране блокировки (на Samsung One UI 8 —
  в Now Bar). Состояние разрешения видно в **Настройки → Dynamic Island-подобный интерфейс**.
- Android 8–15: обычное уведомление с полосой прогресса.
- Действия: «Открыть» (продолжить сессию), «Отложить» (скрыть и напомнить через 30 минут),
  «Завершить» (закрыть сессию; все ответы уже сохранены, оставшиеся карточки дождутся следующего раза).
- Обновляется после каждого ответа, исчезает по завершении, не дублируется после перезапуска.
- Перевод слова в уведомлении не показывается никогда; само слово — только если включено
  «Показывать текущее слово в уведомлении». На экране блокировки по умолчанию скрыто.

Это не «настоящий» Dynamic Island, а стандартное уведомление Android, которое система может показать компактно.
Фирменные «острова» отдельных прошивок (например, HyperOS Focus notifications) используют закрытые API и не поддерживаются.

## Уровень B — плавающая капсула (необязательно)

Горизонтальная капсула поверх других приложений: флаг, счётчик, полоса прогресса, светлая/тёмная тема,
анимация (отключаемая).

**Как включить:** Настройки → «Плавающая капсула поверх приложений» → «Открыть настройки» → разрешите
«Поверх других приложений» для Lingvo Island → вернитесь в приложение.

- Появляется только во время незавершённой сессии и только когда приложение свёрнуто.
- Нажатие — вернуться к тренировке; перетаскивание — переместить; долгое нажатие — скрыть до следующей сессии.
- Располагается ниже строки состояния и выреза камеры, не заходит на системные кнопки.
- Не использует фоновый сервис: если Android выгрузит приложение из памяти, капсула исчезнет,
  а прогресс останется в уведомлении.
- Можно показывать текущую сессию или очереди обоих языков («🇪🇸 8 слов · 🇩🇪 12 слов»).

## Проверка на своём устройстве

1. Начните тренировку, ответьте на 1–2 карточки, сверните приложение.
2. Проверьте уведомление (и чип в строке состояния на Android 16+).
3. Включите капсулу, повторите шаг 1 — капсула должна появиться сверху.
4. Модель телефона и версия Android указаны внизу экрана настроек — пригодится, если что-то работает не так.
