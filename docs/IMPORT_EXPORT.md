# Импорт и экспорт

Экран: **Главная → Импортировать словарь** или **Настройки → Импорт, экспорт и резервные копии**.

## Импорт

1. Выберите язык (🇪🇸 / 🇩🇪) или «Авто» — язык определяется по полю `language` или по ключам `spanish`/`german`.
2. **Файл** (системный выбор файлов) или **Из буфера**. Также можно «Поделиться» JSON-файлом в приложение.
3. Проверьте отчёт: новые, изменённые (с перечнем полей), без изменений, пропущенные (с причиной),
   ошибки в данных, конфликты.
4. **Импортировать**.

Поддерживаемые формы файла: объект `{"schema_version": 1, "language": "es", "entries": [...]}` или просто массив
карточек. Обязательны выражение (`spanish`/`german`, допускается `term`) и `russian` (допускается `translation`).

### Правила слияния

1. Карточка ищется по `id` внутри выбранного языка. Нет `id` или он неизвестен — по нормализованному
   выражению (без учёта регистра, лишних пробелов, формы Unicode, обрамляющей пунктуации; с артиклем).
   Если подходит несколько карточек — запись пропускается, чтобы не угадывать.
2. Пустое поле в файле не стирает заполненное в приложении.
3. Теги и устойчивые сочетания объединяются.
4. Конфликт — если поле отличается, а карточку вы редактировали в приложении, или если различаются личные
   заметки. По умолчанию остаются ваши значения; можно выбрать «Взять значения из файла».
5. Карточки, которых нет в файле, **не удаляются**. Прогресс, история и настройки не меняются.
6. Повторяющиеся в файле записи пропускаются. Повторный импорт того же файла ничего не меняет.
7. Испанский файл не может изменить немецкие карточки, и наоборот. Файл другого языка отклоняется с объяснением.
8. Всё применяется одной транзакцией: при ошибке база остаётся прежней. Перед импортом сохраняется
   автоматическая резервная копия.

### Ошибки

Повреждённый JSON, пустой файл, неверный язык, новая версия формата — импорт не начинается, показывается причина.
Отдельные некорректные записи (без перевода, с недопустимым артиклем) попадают в «Ошибки в данных», остальные импортируются.

## Экспорт

Для каждого языка: **Файл** (сохранить через системный диалог), **Отправить** (Sharesheet), **Копия** (буфер обмена).
Экспорт — канонический JSON без истории повторений; его можно отдать Claude.

## Резервная копия

**Создать** — полный JSON: оба словаря, состояние FSRS каждой карточки, история ответов, настройки.
**Восстановить** — после подтверждения заменяет текущие данные; файл сначала проверяется целиком.
Автоматические копии (последние 5) создаются перед каждым импортом и восстановлением — их можно вернуть
одной кнопкой на том же экране.
