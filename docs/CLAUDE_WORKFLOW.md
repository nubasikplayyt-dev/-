# Пополнение словарей через Claude

## Идея

Вы занимаетесь с Claude как обычно. Новые слова Claude добавляет в **единые** словари проекта:

- `vocabulary/spanish_vocabulary.json` — испанский;
- `vocabulary/german_vocabulary.json` — немецкий.

Затем вы загружаете обновлённый файл в приложение. Приложение само сливает его с тем, что уже есть:
новые карточки добавляются, изменённые обновляются, прогресс обучения не трогается, ничего не удаляется.

## Вариант 1. Claude Code с этим репозиторием (рекомендуется)

1. Попросите: «Добавь в немецкий словарь: die Herausforderung, sich auf etwas verlassen, …».
2. Claude по правилам `CLAUDE.md` вызовет `python3 tools/vocab_tool.py add de …`, проверит дубликаты,
   сделает резервную копию и сообщит, что добавлено.
3. Изменения коммитятся в репозиторий. Скачайте файл (GitHub → `vocabulary/german_vocabulary.json` → Download raw)
   и откройте его на телефоне → «Lingvo Island» (или «Импорт и экспорт → Файл»).

### Обновление в одно касание (публичный репозиторий)

Если репозиторий публичный, вставьте один раз в «Импорт и экспорт → HTTPS-ссылка» адрес файла, например
`https://github.com/<владелец>/<репозиторий>/blob/main/vocabulary/german_vocabulary.json`.
Ссылка запоминается: после каждого занятия с Claude достаточно нажать «Загрузить по ссылке» и «Импортировать».
Для приватного репозитория нужен токен доступа — приложение намеренно не хранит секреты, поэтому используйте файл.

## Вариант 2. Обычный чат с Claude

1. Попросите Claude выдать новые карточки в формате словаря (JSON) — например, массив записей.
2. Скопируйте JSON → в приложении «Импорт и экспорт» → выберите язык → **Из буфера** → проверьте отчёт → **Импортировать**.
3. Чтобы Claude видел, что уже есть, нажмите в приложении «Экспорт → Копия» и вставьте словарь в чат.

## Вариант 3. Файл через «Поделиться»

Любой JSON-файл словаря можно отправить в приложение через системное меню «Поделиться» или открыть
из файлового менеджера — откроется экран импорта с предварительным отчётом.

## Важно

- Приложение **не** синхронизируется с Claude напрямую: у артефактов Claude нет публичного API для этого,
  поэтому передача — через файл или буфер обмена.
- Повторный импорт того же файла безопасен — дубликатов не будет.
- Если вы редактировали карточку в приложении, а в файле другое значение, импорт покажет конфликт и спросит,
  чьё значение оставить. Личные заметки никогда не перезаписываются молча.
- Отправляя словарь Claude, используйте «Экспорт» (только слова). Резервная копия содержит ещё и прогресс —
  её отправлять не нужно.
