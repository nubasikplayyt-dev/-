# Друзья и соревнование

Обмен прогрессом работает по короткому коду. Вы отдаёте код тому, с кем хотите соревноваться,
он вводит его у себя — и видит вашу сводку. Своего сервера не нужно, всё на бесплатном тарифе Firebase.

## Что передаётся

Только ник и счётчики: слова за сегодня и неделю, очки, дни подряд и (по желанию) список изучаемых языков.
**Слова, переводы, примеры и заметки не передаются никогда.** В настройках экрана «Друзья» можно отключить
любую часть: статистику, дни подряд, языки.

Очки за день: один ответ — одно очко, вспомненное слово — ещё одно, выполненная цель дня — плюс 20.
Недельное соревнование обнуляется в понедельник.

## Как пользоваться

1. «Мир» → «Друзья и соревнование» → включить переключатель.
2. Отправить другу код или ссылку-приглашение кнопкой «Пригласить».
3. Друг вводит код в «Добавить друга». Он сразу видит вашу сводку, а вам приходит запрос
   «добавьте меня в ответ» — вы решаете, добавлять его или скрыть.
4. Кнопка обновления сверху подтягивает свежие цифры. Между обновлениями данные видны офлайн.

## Приватность и доступ

- Доступ даёт только код. Кто его знает — видит сводку, поэтому отправляйте его лично.
- Кнопка «Сменить код» закрывает доступ всем сразу: старый код удаляется с сервера.
  Это же и есть блокировка — человек с прежним кодом больше ничего не увидит.
- «Убрать» удаляет друга и его данные с вашего телефона. Сводки, которые не обновлялись 30 дней,
  удаляются сами.
- Вход в аккаунт Google не обязателен: соревнование работает и без него (приложение входит анонимно).
  Вход нужен, если хочется, чтобы ник остался за вами на другом устройстве.
- Чужой человек, знающий ваш код, не может подменить вашу сводку: узел подписан идентификатором
  вашего устройства (поле `owner` в правилах базы).

## Настройка проекта Firebase (делается один раз)

1. [Firebase Console](https://console.firebase.google.com) → проект → **Build → Authentication → Get started**
   → вкладка **Sign-in method** → включить **Anonymous** (и **Google**, если нужен вход в аккаунт).
2. **Build → Realtime Database** → вкладка **Rules** → вставить содержимое `firebase/database.rules.json`
   → **Publish**.
3. **Project settings → Your apps → Android** → package name **`app.lingvo.island`** (именно он указан
   в `applicationId`) → **Register app** → скачать `google-services.json`.
4. В GitHub: **Settings → Secrets and variables → Actions → New repository secret**:
   - `GOOGLE_SERVICES_JSON` — вставить содержимое скачанного файла.

Файл с ключами в репозитории не хранится: сборка берёт его из секрета. Без секрета приложение
собирается и работает как раньше, только экран «Друзья» показывает, что облачные функции недоступны.

## Вход через Google: нужен постоянный ключ подписи

Google проверяет отпечаток SHA-1 того ключа, которым подписан APK. В CI отладочный ключ создаётся
заново при каждой сборке, поэтому нужен свой постоянный ключ:

1. GitHub → **Actions → Create signing key → Run workflow**, придумать пароль.
2. Скачать артефакт `signing-key`, в журнале задачи скопировать строку **SHA1**.
3. Добавить секреты: `KEYSTORE_BASE64` (содержимое файла `lingvo.jks.base64`) и `KEYSTORE_PASSWORD`.
4. Удалить артефакт (кнопка корзины) — ключ остаётся только в секретах.
5. В Firebase: **Project settings → Your apps → Add fingerprint** → вставить SHA-1.

После этого соберите приложение заново и установите APK из новой сборки: он будет подписан
постоянным ключом. Старую версию перед этим придётся удалить — Android не обновляет приложение,
подписанное другим ключом (сделайте резервную копию: «Настройки → Данные и приложение»).

Пока это не сделано, анонимный вход и обмен прогрессом работают, а кнопка «Войти через Google»
сообщает об ошибке.

## Ограничения

- Данные друга обновляются по кнопке, а не сами: это экономит трафик и бесплатный лимит.
- Уведомление «друг обогнал» проверяется во время обновления сводки, то есть с задержкой.
- Бесплатный тариф Firebase (Spark) — 1 ГБ базы и 10 ГБ трафика в месяц; для такого обмена
  это многократный запас.
