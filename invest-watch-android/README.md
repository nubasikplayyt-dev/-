# Портфель по критериям — Android-приложение

Приложение показывает факты и оценки, которые агент мониторинга пишет в
репозиторий [`nubasikplayyt-dev/invest-watch`](https://github.com/nubasikplayyt-dev/invest-watch):
вердикты по критериям владельца, события, дивиденды и цены. Репозиторий оно
читает, а пишет туда ровно один файл — `config/favorites.json`.

Никаких собственных оценок, рейтингов аналитиков, целевых цен, «сигналов» и
прогнозов в приложении нет — ни в интерфейсе, ни в текстах. Это не
инвестиционная рекомендация.

| Папка | Что внутри |
|---|---|
| `core/` | Чистая Kotlin-логика без Android: разбор всех файлов репозитория, критерии, фильтры, расчёты по ценам и дивидендам, отбор уведомлений, слияние избранного. Тесты: `core/src/test` |
| `app/` | Приложение: Compose, Material 3, Hilt, Room, DataStore, WorkManager, Retrofit, Coil, Vico |

## Как поставить на телефон

APK собирает GitHub Actions — ничего устанавливать на компьютер не нужно.

**Из релиза (удобнее):** откройте
[Releases](https://github.com/nubasikplayyt-dev/-/releases) и скачайте
`invest-watch.apk` с телефона. Релиз появляется по тегу:

```bash
git tag investwatch-v1.0.0 && git push origin investwatch-v1.0.0
```

**Из сборки:** Actions → **InvestWatch APK** → последний зелёный запуск →
Artifacts → `invest-watch-apk`. Это zip, внутри `invest-watch.apk`.

Откройте APK на телефоне. Android попросит разрешить установку из того
приложения, откуда вы открываете файл, — разрешите. При первом добавлении
бумаги в избранное приложение попросит разрешение на уведомления.

## Первый запуск

1. Откройте **Настройки** и вставьте fine-grained токен GitHub (как его
   сделать — ниже). Без токена данные не загрузятся.
2. Нажмите **Обновить сейчас**. Приложение заберёт `watchlist.json`,
   статусы, события и дивиденды.
3. Отметьте звёздочкой бумаги на вкладках рынков — они попадут в
   «Избранное» и в `config/favorites.json` репозитория, по которому агент
   решает, что мониторить 4 раза в сутки.
4. Для цен бумаг США и Китая введите ключ источника цен (см. ниже).
   Российским бумагам ключ не нужен.

Посмотреть экраны без токена и сети можно переключателем
**Демонстрационные данные** в настройках: приложение возьмёт встроенный срез
репозитория и три выдуманные бумаги США и Китая.

### Fine-grained токен GitHub, по шагам

1. GitHub → аватар → **Settings** → **Developer settings** →
   **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. **Token name:** `invest-watch android`. **Expiration:** на ваш вкус.
3. **Repository access** → **Only select repositories** → выберите
   `invest-watch`.
4. **Permissions** → **Repository permissions** → **Contents**:
   **Read and write**. Больше ничего включать не нужно.
   Запись нужна только для `config/favorites.json`.
5. **Generate token**, скопируйте строку `github_pat_…` и вставьте в
   настройках приложения.

Токен шифруется AES/GCM ключом из Android Keystore и лежит только на
телефоне. В коде и в репозитории его нет. С приватным репозиторием всё
работает так же.

### Ключ источника цен

- **Россия** — ISS Мосбиржи: официальный API самой биржи, без ключа и
  регистрации. Даёт и котировки, и дивиденды, и ЗПИФ.
- **США и Китай** (Гонконг, Шанхай, Шэньчжэнь) — [EODHD](https://eodhd.com).
  Бесплатного официального API сразу на все эти биржи не существует, поэтому
  здесь коммерческий провайдер: нужен тариф с мировыми биржами. Ключ
  вставляется в настройках, рядом есть кнопка **Проверить** — она делает
  настоящий запрос и показывает, что ответил источник.

Пока бумаг США и Китая в репозитории нет, ключ не нужен вовсе. Без ключа
экран бумаги просто пишет, что цены недоступны, и остальное работает.

Yahoo Finance намеренно не используется: его эндпоинт неофициальный и
отвечает блокировками при регулярных запросах.

## Что на экранах

**Избранное** — главный экран. Вкладка «Бумаги»: карточки избранного с
картинкой, тикером, флагом рынка, типом, вердиктом, ценой с изменением за
день и дивдоходностью против порога рынка. Порядок меняется удержанием и
перетаскиванием и уезжает в репозиторий. Вкладка «Новости»: события только
по избранным бумагам.

**Вкладки рынков** строятся из `markets[]` — появится новый рынок, появится и
вкладка. Внутри: сегмент «Акции / Фонды недвижимости», поиск, фильтры
(вердикт, порог дивдоходности, сырьевые, состав индекса) и сортировки.
Бумаги без `status.json` помечены «Ещё не проверена».

**Экран бумаги:** шапка, линейный график цены за 1М/6М/1Г/5Л/Всё — зелёный,
если за период выросла, красный, если упала; касание показывает дату и цену.
Дивиденды по годам столбцами и таблицей выплат с доходностью к цене на дату
отсечки. Критерии C1–C8 и P1–P3: статус, пометка, расшифровка из `CRITERIA.md`
по нажатию. Решения владельца из `overrides.json` перекрывают оценку агента и
помечены. Дальше метрики, «что отслеживается» и лента событий с фильтром.

**Уведомления:** фоновая проверка раз в 30 минут при наличии сети. Новые
события с `notify: true` по избранным бумагам приходят уведомлением: значок
важности, бумага, заголовок, одна-две строки сводки. Нажатие открывает экран
бумаги. Каналы `critical` и `high` разные — в системных настройках их можно
настроить по-разному. Выключатель по бумаге — на её экране, общий и тихие
часы — в настройках.

## Как добавить бумагу, рынок или тип

Всё правится в репозитории данных, код трогать не нужно.

**Бумага** — объект в `assets[]` файла `config/watchlist.json`:

```json
{
  "id": "MOEX",
  "ticker": "MOEX",
  "name": "Московская биржа",
  "market": "RU",
  "kind": "stock",
  "type": "stock",
  "isin": "RU000A0JR4A1",
  "is_commodity": false,
  "domain": "moex.com"
}
```

Обязательны `id`, `ticker`, `name` и `market`. `domain` нужен для картинки.
Если в `ticker` лежит ISIN (так у ЗПИФ), крупно показывается `id`. Ближайший
ночной запуск агента заполнит `status.json` и `dividends.json`.

**Рынок** — объект в `markets[]`: `id`, `title`, `flag`, `currency`,
`yield_floor_pct`. Вкладка появится сама; если `flag` не указан, он
посчитается по коду страны.

**Тип бумаги** — объект в `kinds[]`: `id` и `title`. Сегмент на вкладке
рынка появится сам.

## Разработка

```bash
# Тесты ядра — Android SDK не нужен
./gradlew -PcoreOnly=true :core:test

# Полная сборка — нужен Android SDK
./gradlew :core:test :app:lintDebug :app:assembleDebug
```

В именах тестов есть кириллица, и Kotlin пишет её в имена файлов классов,
поэтому сборка требует UTF-8 локали: `LANG=C.UTF-8`. В CI это задано.

Логику, которую можно проверить без Android, кладите в `core/` и покрывайте
тестами: `app/` остаётся тонким слоем поверх неё.

В `core/src/test/resources/` два набора: `invest-watch/` — точная копия
репозитория, `mock/` — она же плюс три выдуманные бумаги США и Китая
(компаний не существует, цифры придуманы) для превью экранов. Тот же `mock/`
лежит в `app/src/main/assets/` и питает демонстрационный режим.

## Секреты для подписи APK

Без них APK подписывается отладочным ключом и ставится на телефон как есть.
Чтобы подписывать своим ключом, добавьте в Settings → Secrets and variables →
Actions секреты репозитория:

| Секрет | Что это |
|---|---|
| `INVESTWATCH_KEYSTORE_BASE64` | keystore в base64: `base64 -w0 investwatch.jks` |
| `INVESTWATCH_KEYSTORE_PASSWORD` | пароль хранилища |
| `INVESTWATCH_KEY_ALIAS` | алиас ключа |
| `INVESTWATCH_KEY_PASSWORD` | пароль ключа |

Сам keystore создаётся один раз:

```bash
keytool -genkey -v -keystore investwatch.jks -keyalg RSA -keysize 2048 \
  -validity 10000 -alias investwatch
```

Ключ и пароли в репозиторий не коммитятся.

## Чего в данных пока нет

Часть полей агент ещё не пишет, поэтому соответствующие блоки появляются
сами, когда данные появятся: `status.json → metrics` (блок «Метрики»),
`in_universe` у бумаг (фильтр «В составе индекса»), непустые `dividends.json`,
`events.jsonl` и `feed.json`. Файлы `digests/*.md` приложение не показывает.
