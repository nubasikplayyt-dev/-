# invest-watch

Мониторинг бумаг консервативного портфеля по собственным критериям владельца. Агент по расписанию ищет отчёты, дивиденды и другие факты по бумагам России, США и Китая (акции и фонды недвижимости), оценивает строго по критериям и коммитит сюда. Режимы: `monitor` 4 раза в сутки — избранное и бумаги в зоне покупки/продажи; `screen` раз в сутки — полная проверка очередной порции всей вселенной. Android-приложение читает этот репозиторий и присылает уведомления о важном по избранному.

## Структура
| Путь | Что там |
|---|---|
| `CRITERIA.md` | Критерии качества (C1–C8), цены входа (P1–P3) и исключения владельца |
| `AGENT.md` | Инструкция для агента на каждый запуск |
| `config/watchlist.json` | Рынки, типы бумаг, все бумаги |
| `config/universe.json` | Правила, какие бумаги считаются «самыми популярными» на каждом рынке |
| `config/favorites.json` | Избранное (пишет Android-приложение) |
| `config/overrides.json` | Ручные решения владельца по критериям |
| `data/<id>/dividends.json` | Дивиденды за 10 лет |
| `state/` | Время последних запусков и очередь скрининга |
| `data/<id>/status.json` | Текущая оценка бумаги по критериям и вердикт |
| `data/<id>/events.jsonl` | Значимые события, одна строка — одно событие |
| `schema/event.schema.json` | Формат события |
| `feed/feed.json` | Сводная лента последних событий для приложения |
| `digests/YYYY-MM-DD.md` | Сводка каждого запуска |
| `docs/ANDROID_APP_PROMPT.md` | Промт для Claude Code на создание Android-приложения |

## Охват
Россия: акции из Индекса МосБиржи и все ЗПИФ недвижимости на Мосбирже. США: S&P 100 и REIT из S&P 500. Китай: индекс Hang Seng, REIT Гонконга и 20 крупнейших C-REIT. Правила — в `config/universe.json`.

## Как добавить бумагу
Добавь объект в `assets[]` файла `config/watchlist.json` (`id`, `ticker`, `name`, `market`, `kind`, `domain`). Ближайший ночной `screen` заполнит оценку и дивиденды.

## Как добавить рынок
Добавь объект в `markets[]` (`id`, `title`, `flag`, `currency`, `yield_floor_pct`) и правило в `config/universe.json`. Вкладка в приложении появится сама.

Это не инвестиционная рекомендация.
