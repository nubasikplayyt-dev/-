# CLAUDE.md — правила работы с проектом Lingvo Island

Android-приложение для изучения испанского 🇪🇸 и немецкого 🇩🇪 с интервальным повторением (FSRS-5),
двумя независимыми словарями, импортом JSON, напоминаниями и компактным «Dynamic Island»-подобным
интерфейсом (Live Update-уведомление + необязательная плавающая капсула).

## Структура

| Путь | Что это |
|---|---|
| `vocabulary/spanish_vocabulary.json` | **Канонический испанский словарь** (единый источник, встраивается в APK как стартовый набор) |
| `vocabulary/german_vocabulary.json` | **Канонический немецкий словарь** |
| `tools/vocab_tool.py` | Безопасное пополнение и проверка словарей (только stdlib Python) |
| `core/` | Чистая Kotlin-логика без Android: FSRS, разбор/валидация JSON, слияние при импорте, расписание напоминаний, статусы, резервные копии. Тесты: `core/src/test` |
| `app/` | Android-приложение: Room, DataStore, Compose UI, уведомления, WorkManager/AlarmManager, капсула |
| `docs/` | Инструкции на русском |

## Команды

```bash
python3 tools/vocab_tool.py validate              # проверить оба словаря
python3 tools/vocab_tool.py add de new.json       # добавить карточки (массив или {"entries": [...]})
python3 tools/vocab_tool.py stats
./gradlew :core:test -PcoreOnly=true              # тесты ядра (не нужен Android SDK)
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug   # полная сборка (нужен Android SDK)
```

CI (`.github/workflows/android.yml`) на каждый push проверяет словари, запускает тесты, lint и собирает APK
(артефакт `lingvo-island-apk`).

## Как Claude пополняет словари

Когда пользователь просит добавить испанское слово/выражение — работать **только** с
`vocabulary/spanish_vocabulary.json`; немецкое — **только** с `vocabulary/german_vocabulary.json`.

1. Подготовить новые карточки во временном JSON-файле (вне `vocabulary/`), например:
   ```json
   [{"german": "die Herausforderung", "russian": "вызов, сложная задача", "part_of_speech": "noun",
     "plural": "Herausforderungen", "example_de": "Das ist eine große Herausforderung.",
     "example_ru": "Это большой вызов.", "level": "B2", "tags": ["академическая лексика"]}]
   ```
2. Выполнить `python3 tools/vocab_tool.py add de /путь/к/new.json`. Инструмент сам:
   проверяет дубликаты (регистр, пробелы, Unicode, артикль), не меняет ID существующих карточек,
   не удаляет записи, не стирает заполненные поля пустыми, не перезаписывает личные `notes`,
   объединяет `tags`/`collocations`, ставит фактические `created_at`/`updated_at`,
   обновляет метаданные словаря, создаёт резервную копию в `vocabulary/.backups/`, валидирует JSON
   и отказывается сохранять пустой словарь.
3. Сообщить пользователю, какие записи добавлены, изменены и пропущены (инструмент печатает отчёт).
4. Список слов обрабатывать за один вызов — одним файлом.

Если `vocab_tool.py` недоступен и правка идёт вручную — соблюдать те же правила и обязательно
выполнить `validate` после правки.

### Что заполнять

- Обязательно: выражение (`spanish`/`german`), `russian`.
- По возможности: `part_of_speech` (`noun`, `verb`, `adjective`, `adverb`, `phrase`), пример и его перевод,
  `level` (A1–C2), `tags` (категории: «разговорная лексика», «академическая лексика», «деловая лексика»,
  «медицинская лексика», «политика и экономика», «устойчивые выражения» или свои).
- Немецкие существительные: всегда `article` (`der`/`die`/`das`) и `plural`, если есть. Выражение пишется с артиклем:
  `"german": "die Voraussetzung"`.
- Немецкие глаголы: инфинитив; управление и падеж в `grammar_notes` («auf + Akkusativ»), формы в `verb_forms`
  (`{"präsens_3sg": "...", "präteritum": "...", "perfekt": "..."}`), сочетания в `collocations`.
- Испанский: сохранять ударения, ñ, ¿¡. Для глаголов — управление в `grammar_notes`, неправильные формы в
  `verb_forms`; региональные особенности — в `regional_usage`.
- Устойчивые выражения хранить целиком, с естественным примером.
- Не выдумывать личные заметки (`notes`) или контекст, которых не было в разговоре. `source` — «Claude».
- Похожие, но разные конструкции («sich verlassen» и «sich auf etwas verlassen») — отдельные карточки.

### Чего не делать

- Не создавать новый файл на каждое занятие — пополнять основной словарь.
- Не перезаписывать словарь пустым массивом; не удалять карточки, которых нет в новых данных.
- Не менять `id` существующих карточек; не хранить в JSON историю повторений (она только в базе приложения).
- Не копировать демонстрационную дату — время ставит инструмент.
- Не утверждать, что приложение синхронизировалось само: пользователь импортирует файл вручную (см. ниже).

### Если правка файлов проекта невозможна (например, обычный чат или артефакт)

Честно сказать об этом и выдать готовый JSON (массив новых карточек или весь словарь в формате
`schema_version: 1`). Пользователь импортирует его в приложении: «Импорт и экспорт → Из буфера» или «Файл».
Импорт в приложении идемпотентен: повторная загрузка того же файла не создаёт дубликатов.

## Формат словаря (schema_version 1)

```json
{
  "schema_version": 1,
  "language": "de",
  "updated_at": "2026-10-28T12:00:00Z",
  "entries": [
    {
      "id": "de-0001",
      "german": "die Voraussetzung",
      "russian": "предпосылка; условие",
      "article": "die",
      "plural": "Voraussetzungen",
      "part_of_speech": "noun",
      "example_de": "Das ist eine wichtige Voraussetzung.",
      "example_ru": "Это важное условие.",
      "grammar_notes": "",
      "collocations": [],
      "level": "B2",
      "tags": ["академическая лексика"],
      "notes": "",
      "source": "Claude",
      "created_at": "2026-10-28T12:00:00Z",
      "updated_at": "2026-10-28T12:00:00Z"
    }
  ]
}
```

Испанский: те же поля, но `spanish` и `example_es`; `article` (`el`/`la`/`los`/`las`) — по желанию.
Неизвестные поля сохраняются приложением при импорте и экспорте.

## Правила для изменений кода

- Логику, которую можно тестировать без Android, класть в `core/` и покрывать тестами.
- Схема Room версионируется (`app/schemas/`); менять её только с миграцией, без destructive fallback —
  прогресс пользователя нельзя терять.
- Импорт и восстановление — только в одной транзакции; перед ними — автоматическая резервная копия.
- Не добавлять постоянные фоновые сервисы, wake lock, polling, скрытые API.
- Тексты интерфейса и ошибок — на русском.
